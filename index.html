Features

📊

FPS Overlay

Live FPS readout tuned for gaming and app profiling.

⏱

Frametime

Monitor per-frame latency in milliseconds.

📉

Stutter Detection

Track jitter spikes and log events with a configurable threshold.

📈

Session Stats

Average, minimum, maximum, and P95 framing insights.

🎮

Game Profiles

Limit monitoring to specific app bundle IDs.

⚡

Performance Profiles

Battery, Balanced, and Stability tuning presets.

Install Steps

  1. 1Open Sileo and head to Sources.
  2. 2Tap Edit → Add Source.
  3. 3Paste the repository URL above.
  4. 4Search for FrameBoost and install it.
  5. 5Open Settings → FrameBoost to configure the overlay.
