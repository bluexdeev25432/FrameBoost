FrameBoost docs

Measure your device’s smoothness in real time.

FrameBoost is a real-time FPS overlay and frame pacing diagnostic tweak for iOS 15–16 on Dopamine rootless jailbreaks. It helps you monitor FPS, frametime, stutter events, and per-session performance without altering the hardware.
