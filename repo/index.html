Built for confidence

Monitor frame pacing and performance without changing the hardware.

📊

FPS Overlay

Track live frame rate while gaming or testing apps with a clean overlay tuned for quick reads.

⏱

Frametime Insights

See millisecond-level frame timing and compare how smooth or inconsistent your app feels in real time.

📉

Stutter Detection

Spot pacing drops and export log events to your Documents folder with a configurable stutter threshold.

📈

Session Stats

Review average, minimum, maximum, and P95 readings to understand long-running smoothness, not just a single frame.

🎮

Game Profiles

Enable monitoring only for selected apps using bundle IDs so it stays focused on the titles you care about.

⚡

Performance Profiles

Choose Battery, Balanced, or Stability presets to match your device and workload without opening a terminal.

Quick install

Get FrameBoost running in minutes.

  1. 1Open Sileo or Zebra and go to the Sources tab.
  2. 2Tap Edit → Add and paste the repository URL shown above.
  3. 3Search for FrameBoost, install it, and respring when prompted.
  4. 4Open Settings → FrameBoost and enable the overlay for your preferred apps.
