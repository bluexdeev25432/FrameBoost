FrameBoost

FPS Monitor & Frame Diagnostic
v1.0.0

Features

  • Real-time FPS overlay with adjustable position and style
  • Frametime readout in milliseconds
  • Stutter detection with threshold control
  • Session statistics and P95 frametime
  • Game-specific bundle ID profiles
  • Battery / Balanced / Stability performance presets

Requirements

iOS15.0 – 16.7
JailbreakDopamine (rootless)
Inject libElleKit / libhooker
PrefsPreferenceLoader 2.2.4+

Changelog

  • Initial 1.0.0 release
  • Real-time FPS monitoring with overlay and stutter detection
  • Preference bundle for monitor and overlay controls
  • Game profiles and performance presets

Measurement Note

FrameBoost calculates FPS from CADisplayLink callback intervals. This reflects display cadence, not direct GPU scanout timing. On ProMotion devices, the readings follow the active refresh rate, which makes them a useful monitoring proxy rather than a hardware-accurate performance counter.
